# econometric-analysis-gdp-gds
Econometric analysis of the impact of Gross Domestic Savings on India's GDP Growth (1990–2023).
Project Overview: This project investigates the relationship between Gross Domestic Savings (GDS) and GDP Growth in India using annual time-series data from 1990 to 2023.

A simple linear regression model was developed to evaluate whether higher domestic savings significantly contribute to economic growth.
Problem Statement: H0 :
Gross Domestic Savings do not significantly affect GDP Growth.

H1 :
Higher Gross Domestic Savings significantly increase GDP Growth.
Objectives

Dataset:Period :
1990–2023

Observations :
34

Dependent Variable :
GDP Growth Rate

Independent Variable :
Gross Domestic Savings (% of GDP)

Methodology: Exploratory Data Analysis

Summary Statistics

Simple Linear Regression

Residual Diagnostics

Interpretation

Regression Model: GDP Growth = β₀ + β₁(GDS) + ε

Results: Coefficient = 0.2324

R² = 0.0994

p-value = 0.0694

Diagnostic Tests : Jarque-Bera Test

Breusch-Pagan Test

Breusch-Godfrey Test

Durbin-Watson Test

Key Findings: Positive relationship between GDS and GDP Growth.

Relationship is statistically weak.

Model explains about 10% of GDP variation.

Residuals show no heteroskedasticity or autocorrelation.
